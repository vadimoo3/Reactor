# Reactor Lab

Одна программа для поиска и проверки раскладок реактора. Надстройка над оригинальными алгоритмами из `allalgorithm/`: все они работают внутри, программа их запускает, сводит к одной цели и проверяет результат.

## Как пользоваться

Запустите `ReactorLab.exe`.

Слева:
1. **Способ поиска**
   - **Блоки** — все готовые конструкции архива: блоки Protium с доводкой, модули 3×3, прямые схемы, прибыльные группы с валидатором, точное топливо (reactor-fixed-FUEL), ранняя модель (Nefelium). Лучшее доводится отжигом.
   - **Полный рандом** — чистый случайный (reactor-random), полный случайный перебор вокруг эталона (full-random), направленный случайный с тепловым балансом (reactor-guided), точное топливо (reactor-fixed-FUEL); лучший кандидат доводится отжигом.
   - **Улучшение** — доводит схему, выбранную в списке. Хуже исходной не станет.
2. **Топливо** — Protium, Nefastium или Dolorium с известными значениями из README архива. Для Dolorium доступен только Quad: цен Single и Double в архиве нет.
3. **Стержни** — какие размеры разрешены. Галочка **«Точное количество стержней»** задаёт ровно столько топливных клеток (Quad = одна клетка); без галочки количество любое, а reactor-fixed-FUEL сам перебирает все количества, которые влезают в бюджет.
4. **Улучшения**, которые можно купить на +1 уровень. Поиск сам решает, какие покупки выгодны.
5. **Время** — 5 секунд, 1 минута или 5 минут. Под него масштабируются все этапы: число попыток каждого алгоритма, тики проверок, лимит проверок отбора. Кнопка **Найти** (во время поиска — **Остановить**).

Справа — выбранная схема:
- сетка с иконками; при наведении показываются компонент и соседи;
- цифры из файла и мгновенный пересчёт с вашим сейвом: чистая мощность, производство, охлаждение, цена против бюджета;
- проверка симуляцией запускается сама: два порядка обмена × штатно, Outlet off, Vent off и замена топлива;
- кнопки над схемой: избранное, переименовать, копировать в буфер, сохранить (как схему `.txt` или картинку `.png` в духе draw.py архива), удалить (можно вернуть).

Список **Схемы** — все результаты; сортировка «Новые / Мощные / Избранные», «Вставить» добавляет схему из буфера обмена. В папки заходить не нужно.

Вверху справа — ваш сейв: уровни улучшений, бюджет, цены. Константы игры там же, свёрнуты; менять их не нужно.

## Единая основа

Каждый алгоритм архива искал своё: protium — безопасный переход с авариями, profit — чистую прибыль, modules — цикл работы и остывания, full-random — мутации эталона, random — чистую случайность, guided — случайность с тепловым балансом, fixed-FUEL — заданное топливо, ранняя модель — переходы под бюджеты. Теперь все они генерируют кандидатов, а оценка и проверка общие:

- **Цель** — чистая мощность: `min(производство, автопродажа) − цена заправки / срок топлива`, с учётом Chrono (критерий reactor-profit).
- **Проверка, два уровня**
  - **защищённая** — оба порядка обмена × штатно, Outlet off, Vent off и остывание после выгорания топлива (стандарт reactor-protium и остывание из full-random/modules);
  - **без аварийного запаса** — штатная работа и остывание (стандарт reactor-profit и full-random). Сохраняется с припиской `-без-запаса`, если выгоднее защищённой или защищённой нет.
- **Покупка улучшений** подбирается сама: самый дешёвый набор из разрешённых, с которым схема проходит проверку.

Модель — собственный симулятор архива, не игровой движок (см. README в `allalgorithm/`).

## Папки

```
ReactorLab.exe      программа (движок вшит внутрь)
ReactorLab.ini      ваши настройки (сохраняются сами)
results/            схемы: результаты способов, архивные, вставленные; .trash — удалённые
icons/              спрайты компонентов (Ultimate = T5; Protium = Fuel7, Nefastium = Fuel6, Dolorium = Fuel5)
allalgorithm/       оригинальные алгоритмы и их README, не изменяются
src/
  build.bat         сборка (Visual Studio Build Tools C++); build.bat [путь к exe]
  engine/           движок: rx.h (все параметры), anneal.cpp (отжиг, оценка, отбор), tools.cpp, engine.cpp, engine.manifest (UTF-8)
    algorithms/     все алгоритмы allalgorithm, переведённые на параметры (те же формулы и значения):
                    reactor-protium, -profit, -modules, -full-random, -search (ранняя модель),
                    -random, -guided, -fixed-fuel; Python-скрипты перенесены на C++, рисунок — в «Сохранить»
  app/              интерфейс WPF: Core (модель, движок, топлива, файлы схем), UI (окно по разделам), Theme.xaml
_cleanup/           старые дубликаты после переезда, можно удалить
```

## Проверка

`ReactorLab.exe --selftest <папка>` — самопроверка на копии данных (положите в папку `results`, `icons`, `ReactorLab.ini`). Окно открывается за пределами экрана, отчёт — `selftest-report.txt`, снимки — `*.png` в той же папке. Прогоняет: загрузку, цифры и автопроверку эталонной схемы, топлива, работу со схемами, панель сейва, крайние случаи, все три способа целиком и остановку.

Поиски используют не больше половины ядер процессора и идут с пониженным приоритетом.

Сверка с оригиналом (тот же seed и параметры → тот же результат): validate, validate-profit, thermal-check — все ячейки CSV совпадают; modules, guided, fixed-FUEL — тот же победитель и та же статистика.
